# UX Gap Analysis

## Crítico

- Formulário genérico demais para sistemas com regimes físicos diferentes.
- Campos obrigatórios não eram visualmente identificados.
- Validação dependia demais de erro do core após clique.

## Alto

- Resultados sem hierarquia executiva forte.
- Linguagem com enums internos visíveis.
- Toolbar com agrupamento semântico fraco.
- Painel esquerdo pouco informativo para várias linhas.

## Médio

- Ajuda contextual insuficiente.
- Campos irrelevantes causavam fadiga visual.
- Modo de cálculo não estava explícito na UI.

## Baixo

- Falta de refinamento visual em separadores e grupos.
- Tooltips ausentes em campos técnicos.

## Ações tomadas

- Matriz de comportamento.
- Formulário adaptativo.
- Asterisco vermelho para obrigatórios.
- Tooltips.
- Validação pré-cálculo.
- Painel de requisitos.
- Resumo executivo de resultados.
- PT-BR técnico e labels amigáveis.
