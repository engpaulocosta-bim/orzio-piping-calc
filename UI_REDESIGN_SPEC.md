# UI Redesign Spec

## Main window

- Menu bar com File, Project, Calculation, Export, Help.
- Toolbar com ações comuns: New, Open, Save, Add Route, Duplicate, Calculate, PDF, CSV/XLSX.
- Project explorer na esquerda.
- Formulário de linha no centro.
- Resultados e warnings na direita/baixo.
- Status bar com projeto atual e último cálculo.

## Project explorer

- Projeto no topo.
- Rotas como grupos.
- Linhas como itens selecionáveis.
- Status por linha.

## Input panels

- Projeto.
- Linha/Traçado.
- Fluido/Serviço.
- Operação e projeto.
- Material e catálogo.
- Corrosão/isolamento.
- Geometria/fittings/válvulas.
- Critérios.
- Conferência.

## Results panels

- Summary.
- Hydraulic.
- Thickness.
- Supports.
- Checker.
- Warnings.
- Assumptions.

## Minimum desktop implementation

- Criar projeto.
- Abrir/guardar projeto.
- Criar/duplicar linha.
- Recalcular.
- Exportar PDF.
- Exportar CSV/XLSX.
- Validar inputs antes do cálculo.
