# UI/UX Audit

## Avaliacao honesta

- O programa atual parece tecnicamente competente no core.
- A interface atual parece protótipo interno, não produto vendável.
- A linguagem visual não transmite ainda robustez comercial por depender de Streamlit e por conter mojibake.
- O utilizador entende inputs básicos, mas não tem contexto de projeto/rotas.
- O resultado é explicável, mas está disperso em tabs de cálculo único.

## Problemas principais

- Sem gestão de ficheiros/projetos.
- Sem explorer de rotas.
- Sem histórico persistente.
- Sem comparação de alternativas.
- Sem fluxo desktop nativo.

## Preservar

- Organização por grupos de inputs.
- Status coloridos.
- Tabs de resultados.
- Export PDF e CSV.

## Corrigir

- Migrar para desktop.
- Criar projeto multi-rota.
- Criar painéis persistentes de warnings, assunções e critério governante.
- Corrigir textos e encoding gradualmente.
