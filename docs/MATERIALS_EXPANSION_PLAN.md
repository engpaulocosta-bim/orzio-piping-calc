# Materials Expansion Plan

## Materiais obrigatorios

- Aço carbono: A106 GrB, A53 GrB, A333 Gr6.
- Aço inox: A312 TP304, A312 TP316.
- PVC: PVC-U com catálogos EU e EUA.

## Estrutura alvo

Cada material deve declarar:

- família;
- grade/spec;
- região;
- catálogo dimensional;
- rugosidade;
- densidade;
- envelope de temperatura;
- rating de pressão;
- serviços adequados;
- limitações;
- observações normativas.

## PVC

PVC não deve usar regras de aço por defeito. Deve ter:

- catálogo EU: EN/ISO métrico com PN10/PN16;
- catálogo EUA: ASTM D1785 com SCH40/SCH80;
- limite típico de temperatura de projeto até 60 C no dataset inicial;
- bloqueio para ar comprimido, gás natural, vácuo e fire water;
- warning para temperaturas elevadas;
- rugosidade baixa própria.

## Futuro

Adicionar CPVC, HDPE/PEAD, cobre e PPR através de novos registos, sem alterar os motores.
