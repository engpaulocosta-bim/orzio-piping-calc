# Product Direction

O SIDCT deve evoluir de calculadora técnica de linha única para produto desktop baseado em projetos.

## Produto alvo

- Software desktop independente de navegador.
- Workflow por ficheiro de projeto.
- Múltiplas rotas/traçados independentes no mesmo projeto.
- Cálculo, conferência, warnings e relatórios por linha.
- Comparação de alternativas.
- Materiais e catálogos regionais.
- Relatórios defensáveis para engenharia.

## Posicionamento

Produto técnico para engenheiros MEP, utilities industriais e data centres. A ferramenta deve comunicar limitações de forma honesta, não prometer cálculo normativo completo onde há dataset parcial.

## Prioridade de evolução

1. Projeto persistente multi-traçado.
2. Catálogos/material PVC EU/EUA.
3. UI desktop PySide6.
4. Exportação e relatório.
5. Packaging.
6. Refinamento visual, branding e datasets externos.
