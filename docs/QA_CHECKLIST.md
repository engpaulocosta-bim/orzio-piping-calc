# QA Checklist

- [ ] App desktop abre sem browser.
- [ ] Projeto novo pode ser criado.
- [ ] Projeto pode ser guardado e reaberto.
- [ ] Duas rotas independentes mantêm dados separados.
- [ ] Linha pode ser duplicada sem sobrescrever original.
- [ ] Cálculo aço carbono funciona.
- [ ] Cálculo inox funciona.
- [ ] Cálculo PVC EU funciona.
- [ ] Cálculo PVC EUA funciona.
- [ ] Material inadequado gera erro/warning bloqueante.
- [ ] PDF é exportado.
- [ ] CSV é exportado.
- [ ] XLSX é exportado.
- [ ] Batch CSV é importado.
- [ ] Dataset ausente nunca gera aprovação.
- [ ] Warnings e assunções aparecem na UI.
- [ ] Packaging inclui assets e entrypoint correto.
